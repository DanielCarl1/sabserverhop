# ⚡ SynthZXSHub - Server Hop for Steal a Brainrot

A server hop and brainrot auto-scanner script for **Steal a Brainrot** on Roblox, designed for the **volt.bz** executor.

## Features

- 🔄 **Random Server Hop** — Hop to a random available server
- 🔁 **Rejoin Server** — Rejoin your current server
- 📉 **Smallest Server Hop** — Hop to the server with the fewest players
- 📈 **Biggest Server Hop** — Hop to the server with the most players
- ⚡ **Auto Server Hop** — Automatically hop between servers on a timer
- 🔍 **Brainrot Scanner** — Scans the current server for brainrot items and auto-hops if none are found. Stops hopping when brainrots are detected.
- 🎨 **Clean Blue UI** — Simple, draggable, minimizable interface
- 💧 **synthzxshub Watermark** — Top-right corner watermark

## How to Use

1. Open **Steal a Brainrot** on Roblox
2. Inject with **volt.bz** executor
3. Paste or load `ServerHop.lua`
4. Use the UI buttons to hop or enable auto-scan

## Scanner

The scanner checks the current server's Workspace for objects with brainrot-related names (skibidi, gyatt, rizz, sigma, mewing, fanum, ohio, hawk, tuah, etc). If items are found, it stops hopping and sends a notification. If no items are found, it automatically hops to the next server.
